# คำนวณ last ten blows (PWA)

แอปคำนวณ **ระยะจมหัวเสาเข็มต่อ 10 ครั้งสุดท้าย (last ten blows)** จากน้ำหนักบรรทุกปลอดภัย Qa ที่ต้องการ ด้วยสูตร driving formula 10 สมการ ใช้งานบนมือถือเป็นหลัก ทำงานออฟไลน์ ไม่มี backend (คำนวณใน browser ทั้งหมด)

> ## ⚠ Disclaimer
> แอปนี้เป็นเครื่องมือช่วยคำนวณเบื้องต้นด้วยสูตรเชิงประสบการณ์ (driving formula) ซึ่งมีความไม่แน่นอนสูง ผลลัพธ์ไม่ใช่การรับรองกำลังรับน้ำหนักของเสาเข็ม ต้องยืนยันด้วยการทดสอบการรับน้ำหนักจริง (load test) และการพิจารณาของวิศวกรผู้ออกแบบที่ได้รับใบอนุญาต ผู้พัฒนาไม่รับผิดชอบต่อความเสียหายที่เกิดจากการนำผลไปใช้โดยไม่ตรวจสอบ ค่า FS และค่าพารามิเตอร์เริ่มต้นเป็นเพียงค่าแนะนำ ผู้ใช้ต้องตรวจสอบกับมาตรฐานและเกณฑ์ของโครงการ

## วัตถุประสงค์
หาระยะจมต่อครั้ง *s* ที่ทำให้ Ru จากสูตรตอก = Qa × FS แล้วรายงานระยะจม 10 ครั้งสุดท้าย = 10 × s (มม./ซม.) และจำนวนครั้งต่อ 25 ซม.

## วิธีใช้
1. เลือกชนิด/หน้าตัด/ขนาดเสาเข็ม (หรือ "กรอกเอง"), ใส่ L, f'c (คอนกรีต; Ec = 4700√f'c MPa) หรือใช้ E เหล็ก 200 GPa, Wp
2. เลือกชนิดค้อนและน้ำหนักลูกตุ้ม Wr
3. ใส่ระยะยก H (มีระยะแนะนำให้) และ Qa (ตัน)
4. เลือกสมการ (ENR และ Hiley อยู่บนสุด) ตรวจ FS และพารามิเตอร์ (ทุกตัวมีรายการสำเร็จรูป + "กรอกเอง" + ⓘ คำแนะนำ + เตือนเหลืองเมื่อนอกช่วง)
5. อ่านผลลัพธ์ / กด "เปรียบเทียบทุกสมการ" / แท็บ "รายการคำนวณ" → "พิมพ์/บันทึก PDF" (A4 ไม่เกิน 2 หน้า)

ครั้งแรกที่เปิดแอปต้องติ๊ก "รับทราบ" disclaimer และมีแถบ disclaimer ท้ายจอตลอด

## สมการ ที่มา และ FS (ค่าเริ่มต้น)
หน่วยภายใน SI: m, kN, kN·m, kPa — การแปลงหน่วยทั้งหมดอยู่ในอ็อบเจ็กต์ `U` ใน `index.html` ส่วน `CORE`

| สมการ | สูตร | FS เริ่มต้น (ช่วง) | พารามิเตอร์ |
|---|---|---|---|
| Engineering News (ENR) | Ru = Wr·h/(s+c) | 6 | c = 25.4 มม. (ปล่อยตก) / 2.54 มม. (ไอน้ำ) |
| Hiley | Ru = eh·Eh/(s+(C1+C2+C3)/2) · (Wr+n²Wp)/(Wr+Wp) | 2.5 (2–3) | eh, n, C1, C2 (อัตโนมัติ Ru·L/AE หรือกรอกเอง), C3 |
| Modified ENR | Ru = eh·Wr·h/(s+c) · (Wr+n²Wp)/(Wr+Wp) | 6 | eh, n, c = 2.54 มม. |
| Danish | Ru = eh·Eh/(s+√(eh·Eh·L/2A·Ep)) | 3 (3–4) | ไม่ต้องกรอกเพิ่ม |
| Janbu | Ru = eh·Eh/(Ku·s), Ku = Cd(1+√(1+λ/Cd)), Cd = 0.75+0.15Wp/Wr, λ = eh·Eh·L/(A·Ep·s²) | 3 (3–4) | Cd อัตโนมัติ |
| Gates | Ru = 27√(eh·Eh)(2.4 − log s) [kip, ft-kip, นิ้ว] | 3 (2–3) | eh |
| Pacific Coast (UBC) | Ru = eh·Eh·(Wr+k·Wp)/(Wr+Wp)/(s+C), C = Ru·L/AE | 4 (3–4) | eh, k (เหล็ก 0.25 / อื่น 0.10) |
| Navy-McKay | Ru = Wr·h/[s(1+0.3Wp/Wr)] | 6 | – |
| Eytelwein (Dutch) | Ru = Wr²·h/[s(Wr+Wp)] | 6 (6–10) | – |
| WSDOT | Ru = 6.6·Fe·Wr·h·ln(10N) [kip, ft, N=ครั้ง/นิ้ว] | 2.6 (ประมาณ) | Fe |

ที่มาอ้างอิง: Olson & Flaate (1967) / TTI Report 33-12 (ชุดสูตร ENR, Hiley, Danish, Janbu, Gates, Pacific Coast, Navy-McKay, Eytelwein); Das *Principles of Foundation Engineering*; Bowles *Foundation Analysis and Design*; Tomlinson *Pile Design and Construction Practice*; FHWA GEC-12; WSDOT Standard Specifications 6-05.3(12)B / Geotechnical Design Manual (Allen 2005)

สมการที่แก้ s ตรงๆ ไม่ได้ (Danish, Janbu, Gates, WSDOT) ใช้ bisection — จริงๆ แล้วแอปใช้ bisection กับทุกสมการเพื่อให้โค้ดเดียวกัน และ unit test ตรวจกับคำตอบ closed-form ที่ได้

**FS ของสูตรตอกไม่ใช่ FS ของผลทดสอบการรับน้ำหนักจริง** — ใช้ตามเกณฑ์โครงการ/ผู้ว่าจ้าง

### ข้อมูลที่ "ต้องตรวจสอบ" ก่อนใช้งานจริง
ตอนเขียนแอปไม่สามารถเปิดเอกสารต้นฉบับออนไลน์ได้ (เครือข่ายถูกจำกัด) ค่าต่อไปนี้จึงมาจากแนวตำราและผลค้นหา ยังไม่ได้เทียบกับต้นฉบับ และติดป้าย "ควรตรวจสอบ" ในแอป:
- ตารางขนาดมาตรฐานเสาเข็ม (`SECTIONS`) โดยเฉพาะเสาเข็มรูปตัว I คอนกรีต (ขนาดเป็นค่าประมาณ)
- ตาราง C1 (หมอนรอง × ระดับความเค้น), C3 (quake), Fe ของ WSDOT, ค่า FS ของ WSDOT (≈ γ/φ) และ Pacific Coast (3 หรือ 4)
- ช่วง eh ตามที่กำหนดในโจทย์ (ตำราบางเล่มให้ช่วงกว้างกว่า)
- ค่าคงที่ 0.3 ของ Navy-McKay, รูป C ของ Pacific Coast, การไม่ใส่ eh ใน ENR/Navy-McKay/Eytelwein (ตามสูตรดั้งเดิม)

ตารางทั้งหมดอยู่ใน `index.html` ส่วน `CORE` (`SECTIONS`, `HAMMERS`, `PARAMS`, `EQS`) แก้ได้โดยตรง

## ข้อจำกัด
- ผลลัพธ์จากสูตรเชิงประสบการณ์มีความคลาดเคลื่อนสูง ผลของ cushion/ค้อนจริง/ดิน ไม่ได้ถูกจำลอง (ไม่ใช่ wave equation/PDA)
- ถ้า Ru ที่ต้องการสูงกว่าที่ค้อนให้ได้ สมการจะแจ้ง "ไม่มีคำตอบ" (เช่น ENR ที่ c = 25.4 มม. กับค้อนเบา)
- s < 2 มม./ครั้ง เตือนเสี่ยงตอกหนัก; s > 25 มม./ครั้ง เตือนว่าพลังงานค้อนเกินความจำเป็น

## Deploy บน Netlify
1. ไปที่ https://app.netlify.com/drop แล้วลากไฟล์ `dist/last-ten-blows-deploy.zip` (แตกเป็นโฟลเดอร์ก่อนถ้า Netlify ขอโฟลเดอร์) หรือเชื่อม repo นี้ โดยตั้ง Publish directory เป็น `/` (ไม่มี build command)
2. เปิด URL บนมือถือ → "Add to Home Screen" เพื่อติดตั้ง PWA (ต้องเป็น https)
3. ถ้าแก้ไฟล์ ให้เพิ่มเลข `VERSION` ใน `sw.js` เพื่อให้อุปกรณ์รับไฟล์ใหม่

สร้าง ZIP ใหม่: `python3 tools/build-zip.py`
